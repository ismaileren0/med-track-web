# med-track-web
MEDtrack - AI entegreli ilaç alım ve sağlık takip sistemi

                                        !!!!ÖNEMLİ UYARI!!!!
Siteye giriş yapıldığında önce Gemini API bağlanması gerekir. Aksi taktirde AI özellikleri çalışmaz.

-İlaçlarınızı zamanında almanız için AI tarafından düzenlenen bildirimler
-Kişisel sağlık verilerinize uygun ilaç ve beslenme konusunda AI destekli önerileri
-İlaçlardan kaynaklı olası yan etkilerin takibi ve uyarılar
-Kan tahlili analizi ve değer kontrolü
-Kan tahlili sonuçlarındaki değişimlerin takibi ve buna göre beslenme önerileri
